نور القرآن — نسخة قابلة للتثبيت مع إحصائيات الزيارات

الملفات: index.html و sw.js و manifest.webmanifest و icon-192.png و icon-512.png

لإظهار إحصائيات الزوار:
1. ارفع الملفات إلى مستودع GitHub المرتبط بمشروع Vercel.
2. افتح مشروع Vercel الصحيح ثم افتح Analytics / Web Analytics.
3. اضغط Enable إذا لم تكن مفعّلة.
4. انتظر نشر التعديل ثم افتح الموقع.
5. ارجع إلى Analytics في Vercel لمشاهدة page views والزيارات والأجهزة والبلدان وغيرها حسب البيانات المتاحة.

ملاحظة: الإحصائيات تظهر في لوحة تحكم Vercel، وليست عدّادًا ظاهرًا لزوار الموقع نفسه. وقد تحتاج البيانات بعض الوقت لتظهر. لا يلزم تثبيت حزمة npm للموقع الثابت HTML.
